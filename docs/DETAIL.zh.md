# 会话状态光环

`dsh-session-status` 是 DeepSeek Harness 的会话状态插件。它在输入框上方显示一枚全息状态胶囊，帮助你快速判断当前会话处于待命、执行、完成还是中断状态。

## 状态说明

- **待命**：新会话尚未发送第一条消息。
- **执行中**：模型正在处理当前回合，胶囊会显示实时用时和扫描波形。
- **已完成**：当前回合已经结束，会话空闲；发送新消息后会重新进入执行中。
- **已中断**：发送失败或本轮出现异常。

状态按会话计算，不依赖具体模型。DSH 中的 DeepSeek 账号、API Key 路由或其他可用模型都会正常显示。

## 显示与隐藏

侧栏底部、登录账号入口上方常驻一枚紧凑的眼睛开关。它只控制**当前显示面**：

- 状态在输入框上方时，点击眼睛会隐藏胶囊；再次点击恢复。提示为「隐藏会话状态 / 显示会话状态」。
- 状态已弹出到桌面时，点击眼睛直接隐藏或显示桌面浮窗，不会再唤回输入框胶囊。提示为「隐藏桌面状态 / 显示桌面状态」。
- 两种显示面共享同一份 Host 面板状态，切换显示面时会先收起另一个，任一时刻只会出现一个胶囊。
- 悬停或键盘聚焦时，按钮提示同时显示当前动作、状态和快捷键。
- 右上角状态点始终与当前会话相位同色，不占用输入框空间；状态位于桌面时状态点变为方形，提示眼睛当前控制的是桌面浮窗。
- 侧栏收起时，眼睛开关会自动变为 36px 圆形按钮，仍位于账号入口上方。
- 也可以按 `⌘⇧H`（非 macOS 为 `Ctrl+Shift+H`）切换当前显示面的显示与隐藏。
- 显示面与显示 / 隐藏状态都会跨刷新保留。

账号行由 DSH 的官方单实例槽位占用，第三方插件不能安全覆盖；因此开关固定在账号正上方的侧栏底栏，不遮挡头像和账号菜单的点击区域。

## 显示面切换

在 macOS 上，同一份会话状态有两个显示面：Harness 输入框上方的胶囊，以及独立桌面浮窗。两者由 Host 统一管理：

- 「弹出到桌面」后输入框胶囊立即收起，眼睛开关转为控制桌面浮窗。
- 桌面浮窗的右键菜单或菜单栏图标提供「收回输入框上方」，点击后浮窗收起、胶囊在输入框上方恢复。
- 桌面浮窗自己隐藏或显示时，会通过 Host 同步到眼睛开关，因此两边不会出现状态不一致或两个胶囊。

## 桌面浮窗

点击胶囊上的弹出按钮，或在 DSH 窗口内拖动胶囊，可将状态移动到桌面。桌面浮窗支持：

- 跨 Space 跟随并始终置顶。
- 拖动到任意屏幕和位置，并保存位置。
- 窗口宽度跟随胶囊内容自动收缩；状态文字或计时变长时才扩展，不保留右侧空白。
- 右键菜单提供隐藏、收回输入框上方、重置位置和退出。
- 通过菜单栏状态图标显示、隐藏、收回或退出。

原生桌面浮窗仅支持 macOS；其他平台会使用浏览器窗口回退。

## 安装

在 DSH 的「插件」页面安装 bundle，并指向本插件目录或发布后的 tarball / 包名。

手动安装时，在 `$DSH_HOME/profiles/<profile>/package.json` 中添加：

```json
{
  "dependencies": {
    "dsh-session-status": "link:/absolute/path/to/deepseek-plug"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-session-status"
      ]
    }
  }
}
```

然后在 profile 目录执行 `pnpm install`。没有 HMR 时重启一次 DSH Host。

## 已知限制

- 「已完成」只表示上一回合结束，不代表整个对话永久完成。
- 用时从插件观察到运行态时开始计算，刷新页面后不会保留历史用时。
- 插件只能观察 DeepSeek Harness 内部的会话，无法读取 Cursor、其他 IDE 或独立 API 客户端中的 DeepSeek 调用。
- 原生桌面浮窗仅支持 macOS。
